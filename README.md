# Chrome Extension Aimless

针对 Chrome 和 Firefox 编写的浏览器插件和油猴脚本。

## 开发命令

- `pnpm check`：运行代码检查、类型检查和单元测试。
- `pnpm build:site`：构建文档站和 `.user.js` 油猴脚本。
- `pnpm build:extension`：构建 Chrome MV3 和 Firefox MV2 插件。
- `pnpm build`：构建并验证全部发布产物。

本项目的构建工具在 Node.js 20 上验证。
